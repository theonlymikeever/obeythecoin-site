# obeythecoin-site

The public web pages for **Obey the Coin**, an iOS app: landing, support,
and privacy policy, served via GitHub Pages at
[theonlymikeever.github.io/obeythecoin-site](https://theonlymikeever.github.io/obeythecoin-site/).

These URLs are referenced by the App Store listing — renaming or moving
files here breaks them. The app itself lives in a separate private repo.
